APPLICATION WEB INSTALLABLE (PWA) — iOS et Android

1. Déployer le dossier entier sur un hébergement HTTPS public (index.html à la racine).
2. Ouvrir le site sur iPhone (Safari) ou Android (Chrome) et ajouter à l’écran d’accueil.
3. Le QR code d’accès ne peut être généré qu’après obtention de l’URL publique.
4. Aucun envoi automatique sécurisé de données de santé n’est configuré. Le bouton courriel prépare un brouillon à confirmer.
5. L’application est utilisable hors ligne après première visite réussie en HTTPS. Les réponses ne sont pas enregistrées sur un serveur.
